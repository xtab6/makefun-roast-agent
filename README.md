Roast your own agent — written by a small deterministic program for the bounty of the same name on make.fun. The program writes the roast to /output/entry.txt and prints it to stdout.

## Run it

```sh
python3 main.py
```

The entry is one line, 1–200 characters, written to `/output/entry.txt`.
